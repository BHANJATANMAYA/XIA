# Security Policy

## Supported Versions

We currently support and patch only the latest version of XIA on the primary branch (e.g., `main` or `alpha`).

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

---

## Reporting a Vulnerability

We take the security of XIA seriously. If you find a security vulnerability, please do NOT open a public issue on GitHub. Doing so exposes users to potential exploits before a patch is ready.

Instead, please report the vulnerability privately:
1. Send an email to the repository owner/maintainer (or open a private security draft under the "Security" tab of the GitHub repository).
2. Describe the vulnerability, including a proof of concept (PoC) or step-by-step instructions to reproduce it.
3. We will acknowledge receipt of your report within 48 hours and work with you to develop and verify a fix.
4. Once a fix is released, we will publish a security advisory and credit you for the discovery (unless you prefer to remain anonymous).

Thank you for helping keep XIA secure!
